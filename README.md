# Weather-Forecasting-Analysis
Data Analytics project demonstrating data cleaning, exploration, SQL analysis, and Power BI dashboard creation.
This project analyzes weather data to understand patterns and trends in weather conditions.
The analysis involves data preprocessing, exploratory data analysis, and visualization to study factors such as temperature, humidity, and other weather indicators. 
The goal is to extract insights that help in understanding weather behavior over time. 
This project demonstrates skills in data analysis and visualization using Python and Power BI.
